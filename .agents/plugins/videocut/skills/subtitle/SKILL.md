# 字幕稿清理（subtitle）

把 ASR 产出的原始 SRT 整理成可交付的字幕文件。**纯文本工作，不动视频。**

## 前置条件

- 已有 `<base_dir>/work/transcript.srt`（由 videocut_process 产出）。
  没有就先走 transcript 技能完成转录；ASR 不可用时返回 asr_runtime_missing，
  按提示运行 scripts/bootstrap-asr.ps1。

## 工作流

1. **读原始稿**：读 `<base_dir>/work/transcript.srt`，统计条数/总时长。
2. **顺文本**（按优先级）：
   - **专名纠正**：对照热词表与上下文修正识别错误（"cli"→"CLI"）。
   - **去口水词痕迹**：嗯/呃/那个 若已转成文字，删掉并**合并被拆断的相邻条目**
     （删文字后两条间隔 <0.3s 应合并，避免字幕闪跳）。
   - **标点规范化**：ASR 通常无标点，按语义补句读/逗号/问号；长句 >25 字断成两条。
   - **数字与单位**："三个g"→"3GB"、"二零二六"→"2026"，按语境统一。
3. **校时间轴**：
   - 每条字幕停留 ≥0.8s（低于则与相邻条合并或微调 end）。
   - 相邻条间隔 ≥0.05s（重叠会让播放器闪跳；微调后一条的 start）。
   - 不改变叙事时序——**只微调，不重排**。
4. **写成品**：另存为 `<base_dir>/work/subtitle_clean.srt`，
   **不覆盖原始 transcript.srt**（保留可追溯源）。
5. **交付**：报告条目数变化（如 214→187 条）、修改类型统计。

## 边界与注意事项

- **不烧录**：当前版本没有字幕烧录工具。用户要"把字幕压进视频"时明确告知，
  可建议用 ffmpeg 的 `subtitles` filter 自行处理（给出命令模板），
  或等待后续版本；**不要假装能烧**。
- 改动 >30% 的条目时，向用户展示修改样例（前后对比 5 条）再全量落地。
- SRT 编码统一 UTF-8；时间轴格式 `HH:MM:SS,mmm`，逗号分隔，勿用点号。
