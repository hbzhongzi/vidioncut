本次优化点（对照当前版本）

以下为界面与交互调整清单；标注「前端」的改动不涉及 Go 后端，确认设计稿后即可动手。

视觉

  • 深色专业工具风：默认深色主题（剪辑软件主流观感），保留浅色可切换；替换 Element Plus 默认浅色皮肤
  • 双栏工作台布局：左侧「预览 + 时间轴」主工作区，右侧「文件信息 / 策略 / 输出 / 操作」设置栏，信息层级更清晰
  • 策略卡片化：流复制 / 重编码 / 仅音频改为带说明的选项卡，替代裸下拉框
  • 统一视觉语言：圆角卡片、渐变主按钮、彩色状态标签、等宽数字时间显示

顺手度

  • 拖放添加：文件直接拖入窗口即可添加，批量/合并支持多选拖入（前端）
  • 时间轴升级：刻度尺 + 选区手柄 + 快捷「播放选区 / 设入点 I / 设出点 O / 中点分割」（前端）
  • 时间输入：支持 mm:ss.s 格式直接键入，附带 ±0.5s 微调键（前端）
  • 批量进度：表格内区间缩略条 + 每项状态 + 底部「n/N 项 · 整体进度」汇总
  • 合并排序：片段卡片支持拖拽调整顺序，实时显示合计时长（前端）
  • 处理中反馈：主按钮变为进度态 + 预计耗时 + 随时取消；完成后突出「打开所在文件夹」
  • 快捷键：空格播放/暂停、I/O 设入点出点、←→ 微调（前端）
