设计说明（对应《字幕功能更新文档》与开发文档 §19.14）： ① 字幕是 AI 粗剪的第三步（合并成片之后），核心是剪后时间轴重对齐——源轴字幕按保留段平移、删除段内容剔除、跨段边界用词级时间戳断开（列表中以「⚡跨段词级断开」标注）； ② 默认外显：SRT/ASS 独立文件直通剪映/PR 精修，WebView2 预览不渲染外挂字幕属预期（看列表文本）；内嵌/双出需重编码，烧录为独立异步任务（复用批量任务契约与 trim:progress 事件）； ③ 烧录界面标注编码器 / crf / 预计剩余时间；GPU 编码（NVENC/QSV/AMF）为可选项，启动失败自动回退 libx264； ④ Codex 面板可见 videocut_export_subtitles / videocut_burn_subtitles 两个新工具（MCP 12 → 14）调用轨迹；字幕配置集中于 config.yaml 的 subtitles 段； ⑤ 浅色主题覆盖字幕条列表 / 模式卡片 / 烧录进度条 / 特效 chips（屏 5 验证主题变量完整性）； ⑥ 二次加工（屏 4）：Codex 读字幕文本 → 五维分析（关键词密度 / 内容类型 / 平均句长 / 节奏 / 情感强度，全部读自 motion-plan.json 的 analysis 字段，前端纯展示不重复计算）→ **两级规则引擎**自动选特效（Level 1 内容类型互斥、命中即停取主技能；Level 2 特征规则按序补充，上限 2、可单项禁用、理由可查）→ edited_fx.ass；特效由 ASS override tags 承载（marker-sweep 用 \kf 逐词填充模拟扫描，放弃 \p1 矢量路径），**烧录命令不变**；libass 不支持的效果（blur-reveal）明确降级并记入 rejected。
